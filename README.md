# Flipkart Laptop Web Scraping & EDA

A Python data analysis project using **web scraping and Exploratory Data Analysis (EDA)** to analyze laptop prices, brands, ratings, discounts, processors, storage, and customer engagement.

## 🎯 Objectives

- Scrape laptop data from Flipkart
- Clean and preprocess the dataset
- Analyze laptop prices and discounts
- Compare brands and processors
- Analyze ratings and customer reviews
- Identify best-value laptops

## 🔍 Key Analysis

- Laptop price segments
- Brand-wise price and rating analysis
- Processor-wise analysis
- SSD vs HDD comparison
- Discount patterns
- Customer engagement
- Price–rating correlation
- Best-value laptop identification

## 🛠️ Technologies Used

**Python • Pandas • NumPy • BeautifulSoup • Requests • Matplotlib • Seaborn • SciPy • Statsmodels**
